# Revit Phases 14–16 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add Revit 2027 native-authoring integration, Library-plugin contract resolution, and hydraulic-specific refinement without coupling CBIM Core to Revit.

**Architecture:** Python emits a stable Revit Build Plan from CBIM; separate C# Revit hosts consume it. Library and hydraulic capabilities integrate through explicit contracts so all recognition remains in CBIM Core.

**Tech Stack:** Python 3.11+, Pydantic, CBIM SDK 0.4, C#/.NET 8, Autodesk Revit 2027 API (local build only), PowerShell.

**Spec:** `docs/superpowers/specs/2026-08-21-revit-phases-14-16-design.md`

## Global Constraints
- No proprietary manufacturer family files in the package.
- Revit 2027 host must build against locally installed `RevitAPI.dll` and `RevitAPIUI.dll`.
- CBIM Core remains Revit-independent.
- Plugins remain separate installable add-ins but share contracts.
- TDD for Python production behavior.
