# CompatibilizaBIM v1.2.0 — SINAPI + Orçamento 5D

Esta entrega mantém as Fases 1 e 2 anteriores e adiciona uma camada SINAPI desacoplada do motor BIM.

## Entregue
- importação mensal ZIP/XLSX;
- versionamento/SQLite/procedência SHA-256;
- pesquisa por UF e competência;
- sugestões de composição sem confirmação automática;
- mapeamento BIM/QTO → composição;
- geração de PriceBook SINAPI;
- comparação e reorçamento entre competências;
- CLI e interface desktop.

## Restrição de segurança econômica
Os arquivos `samples/sinapi-demo-*.zip` não são publicações oficiais e não devem ser usados em obra real. O sistema preserva a origem do arquivo importado para permitir auditoria da base efetivamente utilizada.
